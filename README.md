# نوبان — برنامه‌ریز کشیک بیمارستان

این پروژه کاملاً فرانت‌اند است و برای اجرا فقط به مرورگر نیاز دارد. اطلاعات کاربران در `localStorage` همان مرورگر ذخیره می‌شود و به سرور ارسال نمی‌شود.

## انتشار روی GitHub Pages

1. یک Repository جدید در GitHub بسازید.
2. فایل‌های `index.html` و `README.md` را در ریشه Repository آپلود کنید.
3. در GitHub وارد `Settings > Pages` شوید.
4. در بخش `Build and deployment`، گزینه `Deploy from a branch` را انتخاب کنید.
5. Branch را روی `main` و Folder را روی `/ (root)` قرار دهید و `Save` را بزنید.
6. پس از چند دقیقه آدرس سایت به‌شکل زیر فعال می‌شود:

   `https://USERNAME.github.io/REPOSITORY/`

## اجرای محلی

فایل `index.html` را مستقیماً در مرورگر باز کنید. برای تجربه مطمئن‌تر می‌توانید از افزونه Live Server در VS Code استفاده کنید.

## ساختار

- `index.html`: کل رابط، استایل‌ها و منطق برنامه
- `README.md`: راهنمای اجرا و انتشار
